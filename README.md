# Mikloset live account preview

[Open the Flutter preview](https://maybedev913.github.io/mikloset-demo/).

This preview connects to Mikloset's encrypted development backend. Choose Log In
and enter your existing Dev account to browse its closet, pending purchases,
saved looks, profile, stores, email access, followers and notifications.

Browsing only: editing, imports, Gmail grants, signup and billing are not enabled.
Browser sessions stay in memory, so refreshing the page requires signing in again.
No test credentials or account data are included in this static release.

This repository hosts compiled Flutter assets. Application source remains private.
