# Mikloset interactive demo

Open the [interactive preview](https://maybedev913.github.io/mikloset-demo/).

This repository hosts generated Flutter web files only. The application source
is maintained separately. The preview uses local sample data and clearly labeled
simulated services; it does not connect real Mikloset accounts, Google, Gmail,
retailers or billing providers. Use **Preview the mobile app** to explore without
entering credentials.

The approved smooth upward opening plays on the first browser visit. Saved demo
looks and the opening completion preference may remain in browser-local storage.

The Pages workflow publishes updates to the static files in this repository.
Interactive Mikloset Flutter preview with local sample data and simulated services.
